# Aurora incident review: 2025-02-14

The Aurora portal was unavailable for 23 minutes after a deployment introduced
an invalid cache key. Requests bypassed the cache and exhausted the API worker
pool. The on-call engineer rolled back the release, restored normal traffic,
and opened a follow-up task for a pre-deployment cache validation.

The incident did not expose customer data. The next release must include a
canary check for cache-key compatibility and an alert for worker-pool
saturation.
